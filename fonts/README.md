# Source Sans 3

The interface uses the original Source Sans 3 variable font from Google Fonts.
It is served locally so the game remains fast, private and available offline.

The unmodified family covers the complete `200-900` weight range. PartyRush
uses regular weights for body copy, semibold or bold weights for controls, and
extra bold only for the main card sentence and the largest headings.

stored in `OFL-SourceSans3.txt`.
